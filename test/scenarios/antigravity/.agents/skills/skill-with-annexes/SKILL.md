# Compétence avec Fichiers Annexes

Ce skill possède des fichiers dans `scripts/` et `references/`.
L'extension doit scanné **uniquement** ce fichier `SKILL.md` au boot.
Les annexes ne consomment aucun token tant qu'elles ne sont pas lues sur disque.
