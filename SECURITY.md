# Politique de sécurité

## Versions prises en charge

| Version | Correctifs de sécurité |
|---|---|
| 0.4.x | ✅ |
| < 0.4 | ❌ |

## Signaler une faille

Ne signalez pas une faille dans une issue publique.

Utilisez le signalement privé des vulnérabilités de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**, ou directement [ce formulaire](https://github.com/divadparad-gmail/skills-rules-manager/security/advisories/new). Seuls vous et le mainteneur voyez le signalement.

Indiquez la version concernée, l'éditeur hôte (VS Code ou Antigravity IDE), l'impact constaté et les étapes pour reproduire le problème.

Un accusé de réception vous est adressé dans un délai d'une semaine. La faille est rendue publique une fois la version corrigée disponible, en accord avec vous.
